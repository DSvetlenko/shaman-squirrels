# Шаман: белки над пропастью

Мобильная игра по мотивам «Трагедии белок». Ты шаман: белки сидят в дупле, а орехи лежат на соседних парящих островах. Ставь доски, ящики и батуты, трать магию и выпускай белок. Они сами идут к орехам, берут по одному и несут домой. Уровень пройден, если вернулось не меньше заданного числа.

Игра: **https://dsvetlenko.github.io/shaman-squirrels/**

## Установка на iPhone

1. Открой ссылку в **Safari** (в Chrome на iPhone установить нельзя).
2. Нажми «Поделиться» (квадрат со стрелкой).
3. Выбери «На экран „Домой“» → «Добавить».
4. Запускай игру с иконки. Она откроется на весь экран, без адресной строки.
5. Один раз открой игру при интернете. Дальше она работает офлайн.

## Установка на Android

Открой ссылку в Chrome → меню ⋮ → «Добавить на главный экран» или «Установить приложение».

## Прогресс

- Сохраняется на устройстве автоматически: после каждого уровня, при сворачивании и закрытии.
- Хранится в IndexedDB, рядом лежит резервная копия и дубль в localStorage. Если основная копия повредится, игра возьмёт резервную.
- Обновления игры прогресс не трогают: он хранится отдельно от файлов игры.
- В Настройках есть «Сохранить копию» (файл JSON можно положить в «Файлы» или отправить себе) и восстановление из файла или текста.
- Важно для iPhone: если долго не открывать игру, Safari может очистить данные сайта. Иногда сохраняй копию. Прогресс в Safari и в установленной на экран «Домой» игре хранится раздельно, играй через иконку.

## Как устроен проект

```
index.html, manifest.json, service-worker.js   PWA
css/app.css                                    интерфейс
levels/levels.json                             все уровни (данные отдельно от кода)
src/config.js                                  баланс: предметы, физика, скорость белок
src/main.js                                    экраны, ход уровня, обновления
src/scenes/GameScene.js                        игровая сцена Phaser: острова, физика, установка предметов
src/entities/                                  белка и предметы шамана
src/systems/                                   геометрия, прогресс, звёзды, достижения
src/save/                                      сохранения, резервные копии, миграции формата
src/art/                                       векторная графика игры
src/core/                                      звук, шина событий
src/ui/                                        иконки и картинки интерфейса
assets/                                        звуки, шрифты, иконки, заставки
tools/                                         сборка, проверки, локальный сервер
```

## Публикация

Каждый пуш в ветку `main` запускает GitHub Actions (`.github/workflows/pages.yml`): проверка уровней, сборка `service-worker.js` с новой версией кэша и публикация на GitHub Pages. Телефон при следующем запуске скачает обновление сам.

Если делаешь репозиторий заново: Settings → Pages → Source → **GitHub Actions**.

## Локальный запуск

```bash
node tools/serve.mjs      # http://localhost:8080
```

## Проверки

```bash
npm install && npx playwright install chromium
npm run check     # поля уровней и стоимость решений
npm run verify    # физика: каждый уровень проходится эталонным решением и не проходится без предметов
npm test          # экраны iPhone SE / 13 / 15 Pro Max / Pixel 7, сохранения, миграции, офлайн
```

Тесты идут в Chromium с эмуляцией телефонов. Это не замена проверке на настоящем iPhone.

Добавление уровней описано в [LEVELS.md](LEVELS.md), лицензии ресурсов — в [ASSETS.md](ASSETS.md).
