# Как добавить уровень

Все уровни лежат в одном файле: `levels/levels.json`. Код игры трогать не нужно.

## Коротко

1. Открой `levels/levels.json` на GitHub (значок карандаша, «Edit this file»).
2. Скопируй блок любого уровня, вставь его в конец списка `levels` и поменяй значения.
3. Обязательно придумай **новый уникальный `id`**, например `w2-01`. По id хранится прогресс, поэтому id существующих уровней менять нельзя.
4. Нажми «Commit changes». Через 1–2 минуты GitHub Actions опубликует обновление.
5. На телефоне открой игру. Она скачает новую версию и перезапустится в меню. Пройденные уровни, звёзды и статистика сохранятся.

Порядок уровней в игре равен порядку в файле. Уровень открывается, когда пройден предыдущий по списку. Если вставить новый уровень в середину, уже открытые уровни игрока останутся открытыми.

## Поля уровня

```json
{
  "id": "w2-01",                 // уникальный, не менять после публикации
  "world": 2,
  "name": "Новый мост",          // лучше до 14 символов, чтобы влезало в шапку
  "special": false,              // true — карточка «Испытание»
  "squirrels": 5,                // сколько белок в дупле
  "goal": 4,                     // сколько должно вернуться для победы
  "mana": 40,                    // запас магии
  "timeLimit": 120,              // секунд на забег
  "spawnInterval": 1.15,         // пауза между выходом белок, сек (необязательно)
  "items": { "plank": 2, "longPlank": 1, "crate": 1, "trampoline": 0 },
  "stars": { "mana": 25, "timeSec": 20 },   // условия 2-й и 3-й звезды
  "hollow": { "x": 60, "y": 300, "dir": 1 }, // дупло: x, поверхность острова y, направление 1 вправо / -1 влево
  "nuts": { "x": 340, "y": 300 },            // орехи: x и поверхность y
  "islands": [ { "x": 10, "y": 300, "w": 150, "depth": 160, "seed": 5 } ],
  "spikes": [ { "x": 150, "y": 380, "w": 60 } ],
  "props": [],                   // заранее стоящие предметы, формат как в solution
  "tips": ["Текст подсказки"],
  "solution": [ { "type": "plank", "x": 200, "y": 305, "angle": 0 } ]
}
```

### Координаты

Поле уровня — 400 × 520 условных единиц, начало в левом верхнем углу, `y` растёт вниз. Белки ходят по верхнему краю острова (`y` острова). Ниже 640 — пропасть.

### Предметы

| Тип | Что делает | Магия |
|---|---|---|
| `plank` | доска 120, концы прибиваются к краю острова или к концу другой доски | 15 |
| `longPlank` | доска 180 | 25 |
| `crate` | ящик 40 × 40, падает и служит ступенькой, закрывает шипы | 10 |
| `trampoline` | висит там, где поставлен, подбрасывает белку на ~290 вверх по ходу движения | 30 |

Белки сами перепрыгивают ступеньку до ~45 и не поднимаются по склону круче 38°.

### Эталонное решение

Поле `solution` — список предметов, которыми уровень проходится. Для доски указывается центр и угол в градусах. Решение не показывается игроку, оно нужно для проверки.

## Проверка

```bash
npm install
npx playwright install chromium
npm run check    # быстрая проверка полей и стоимости решения
npm run verify   # прогоняет физику: с решением уровень должен проходиться, без предметов — нет
npm test         # проверки сохранений, офлайна и экранов
```

`npm run check` запускается и в GitHub Actions перед каждой публикацией. Если в файле ошибка, публикация остановится, а игра на телефоне останется прежней.
